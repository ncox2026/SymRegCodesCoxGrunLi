Symreg is a shorthand for symbolic regression and models with equation are the final equation chosen for that particular beam energy. Emulation is for the models which take the input parameters X and K to predict the observables F1 and v2. Inversion is for models which infer X and K from F1 and v2.

xytrain90.dat holds 90 data points from an IBUU simulation of Au+Au collisions at beam energies of 1.23A GeV. This data is used to train and test models with the HADES distinction.
The other datasets have 120 data points at varying beam energies/nucleon in MeV, and is used to train the rest of the models.

The Results folder has every equation generated by our symreg tests at all beam energies sorted by type
Non-interactive plots are pdf files created by Python, while interactive plots are html files that can be downloaded and run in a browser.
Data from time testing includes the results from the emulators being called 1 million times.

3Dinteractive and DNN plots generated different plots, symreg and scatter3d are dependencies in other codes, and the equation generation code generated all equations used.
The miscellaneous code has a plot generator, converts files into latex tables, and generates plots as well
